# Dot to Dot — 동덕여자대학교 제47회 실내디자인 졸업전시

제공된 `웹 페이지 디자인.pdf`와 메인 페이지 PNG를 바탕으로 만든 1차 프론트엔드입니다. React 19 + TypeScript + Vinext(Vite)를 사용하며, 배포 결과는 서버 없이 동작하는 정적 웹사이트입니다.

## 실행

Node.js 22.13 이상이 필요합니다(Node 24 권장).

```bash
npm install
npm run dev
```

터미널에 출력되는 로컬 주소를 브라우저에서 여세요.

```bash
npm run build
npx tsc --noEmit
```

정적 배포 파일은 `dist/client/`에 생성됩니다. 임의의 정적 웹 호스팅에도 배포할 수 있습니다. 중첩 URL은 해당 디렉터리의 `index.html`로 연결해야 합니다.

## 구현 범위

- 홈: 제공 로고, 푸른 그라데이션, 스크롤 연동 궤도, 전시 소개, 일정, 전시장 안내도, 참여자 및 지도교수
- 프로젝트: 2개 분야 탭, 이미지 확대 및 어두운 오버레이, 분야별 상세 페이지
- 디자이너: PDF 참여자 20명, 가나다순 정렬, 이름별 앵커
- 공통: 스크롤 헤더, 검색 다이얼로그, 십자/그라데이션 커서, 모바일 레이아웃
- 접근성: 키보드 포커스, 다이얼로그 포커스 관리, 모션 감소 설정 대응, 이미지 대체 텍스트

## 자료 교체

- `lib/exhibition.ts`: 참여자, 학과, 작품명·설명·이미지 데이터
- `public/assets/`: 원본 PNG 4개와 PDF에서 추출한 전시장 안내도·예시 공간 이미지
- `app/page.tsx`: 전시 소개·일정·주소
- `components/exhibition/shell.tsx`: 메뉴, 검색, 인스타그램 연결, 커서 효과
- `app/globals.css`: 공통 디자인·반응형·모션

현재 프로젝트 2개는 실제 출품작이 아닌 **PDF 예시 이미지 기반의 상세 화면 시안**입니다. 디자이너 사진·이메일·작품 연결은 자료가 없어 생성하지 않았고, 프로필 준비 중 상태를 표시합니다. 공식 인스타그램 URL을 받은 후 현재 안내 다이얼로그를 링크로 교체하면 됩니다. 이름과 일정은 제공 PDF에 기반하며 최종 자료로 교정할 수 있습니다.

전시 소개 왼쪽에는 후속 요청으로 제공된 `poster_animation.mp4`를 적용했습니다. 원본 비율을 유지하고 무음 자동 반복 재생하며 기본 재생 컨트롤로 일시정지할 수 있습니다. 메인 히어로는 SVG 궤도 효과를 유지합니다.

백엔드·데이터베이스·관리자 화면·업로드 기능은 포함하지 않았습니다. 추후 작품 데이터를 API로 바꾸기 쉽게 분리했습니다.

## 메인 모션 업데이트

`public/assets/orbits-animated.svg`는 배경 없는 SVG 애니메이션입니다. 궤도마다 18–26초 주기로 선과 점이 반복 이동합니다. `orbits-transparent.svg`는 정지 이미지입니다. CSS의 `.hero-stage` 높이로 스크롤 길이를, `--exit`를 사용하는 scale·blur 값으로 확대와 흐림 정도를 조절할 수 있습니다. 모션 감소 설정에서는 고정 스크롤 구간과 반복 이동을 해제합니다.
